**FurnitureShop** — web-приложение интернет-магазина мебели с системой интеллектуальных рекомендаций товаров.

Проект разработан в рамках выпускной квалификационной работы на тему:

> «Разработка web-приложения интернет-магазина мебели с системой интеллектуальных рекомендаций»

---

## О проекте

FurnitureShop предназначен для автоматизации основных процессов интернет-магазина мебели: просмотра каталога, поиска и фильтрации товаров, оформления заказов, управления пользователями, товарами, заказами и складскими остатками.

Отдельная часть проекта — модуль интеллектуальных рекомендаций. Он подбирает похожие и сопутствующие товары на основе характеристик продукции, текущего товара, корзины, истории заказов и связей между товарами.

---

## Основные возможности

### Пользовательская часть

- просмотр главной страницы и каталога товаров;
- поиск и фильтрация мебели по характеристикам;
- просмотр подробной карточки товара;
- работа с корзиной;
- добавление товаров в избранное;
- оформление заказа;
- регистрация и авторизация;
- личный кабинет пользователя;
- просмотр истории заказов;
- отображение рекомендованных товаров.

### Административная панель

- управление товарами;
- добавление и редактирование изображений;
- управление заказами;
- изменение статусов заказов;
- управление пользователями;
- настройка товарных атрибутов;
- управление категориями, цветами, стилями, материалами и комнатами;
- просмотр складских данных.

### Складской модуль

- просмотр заказов в обработке;
- контроль наличия товаров;
- изменение складских остатков;
- подготовка заказа к выдаче или доставке.

### Система рекомендаций

- подбор похожих товаров;
- подбор сопутствующих товаров;
- учет категории, стиля, комнаты и других атрибутов;
- учет истории заказов пользователя;
- использование ручных связей между товарами;
- резервный вывод популярных товаров при отсутствии персональных данных.

## Архитектура проекта

Проект построен как классическое серверное web-приложение на PHP.

Основные части системы:

- **пользовательская часть** — каталог, карточка товара, корзина, избранное, оформление заказа;
- **административная панель** — управление товарами, заказами, пользователями и атрибутами;
- **складской модуль** — контроль остатков и обработка заказов;
- **модуль рекомендаций** — подбор релевантных товаров;
- **база данных** — хранение пользователей, товаров, заказов, избранного, изображений и справочников.

## База данных

В проекте используется реляционная база данных MySQL.

Основные таблицы:

| Таблица | Назначение |
|---|---|
| `users` | хранение пользователей и ролей |
| `products` | хранение товаров |
| `product_images` | дополнительные изображения товаров |
| `orders` | заказы пользователей |
| `order_items` | состав заказов |
| `wishlist` | избранные товары |
| `product_related` | связи между товарами |
| `attr_categories` | категории товаров |
| `attr_colors` | цвета |
| `attr_materials` | материалы |
| `attr_styles` | стили |
| `attr_rooms` | комнаты размещения |
| `attr_category_links` | связи между категориями |
| `attr_room_links` | связи комнат и категорий |

## Установка и запуск

### 1. Склонировать репозиторий

```bash
git clone https://github.com/username/FurnitureShop.git
```

```bash
cd FurnitureShop
```

### 2. Разместить проект на локальном сервере

Для запуска можно использовать OSPanel.

Пример расположения проекта:

```text
OSPanel/home/FurnitureShop/
```

После размещения проект должен быть доступен через локальный домен или localhost.

---

### 3. Создать базу данных

В phpMyAdmin необходимо создать базу данных:

```sql
CREATE DATABASE furniture_shop CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

Затем импортировать SQL-дамп:

```text
sql/furniture_shop.sql
```

---

### 4. Настроить подключение к базе данных

Файл подключения:

```text
includes/db.php
```

Пример настроек:

```php
$host = '127.0.0.1';
$port = '3306';
$db   = 'furniture_shop';
$user = 'root';
$pass = '';
$charset = 'utf8mb4';
```

Для OSPanel адрес хоста может отличаться. Если MySQL привязан к другому адресу, укажите его в `$host`.

---

### 5. Запустить проект

После настройки базы данных и подключения открыть проект в браузере:

```text
http://furnitureshop/
```

или

```text
http://localhost/FurnitureShop/
```

## Модуль рекомендаций

Рекомендательный модуль находится в файле:

```text
includes/recommendations.php
```

Он анализирует:

- текущий просматриваемый товар;
- товары в корзине;
- историю заказов пользователя;
- связи между товарами;
- категорию товара;
- стиль;
- комнату размещения;
- связанные категории.

На основе этих данных формируется список релевантных товаров, которые отображаются пользователю в интерфейсе.

Если персональных данных недостаточно, система выводит популярные товары.

## Основные пользовательские сценарии

### Просмотр и выбор товара

1. Пользователь открывает каталог.
2. Применяет поиск или фильтры.
3. Переходит в карточку товара.
4. Изучает описание, изображения и характеристики.
5. Добавляет товар в корзину или избранное.

### Оформление заказа

1. Пользователь открывает корзину.
2. Проверяет список товаров и итоговую сумму.
3. Переходит к оформлению заказа.
4. Указывает контактные данные.
5. Система проверяет наличие товаров.
6. Заказ сохраняется в базе данных.
7. Пользователь перенаправляется в личный кабинет.

### Администрирование

1. Администратор входит в административную панель.
2. Управляет товарами, заказами и пользователями.
3. Изменяет характеристики товаров.
4. Контролирует статусы заказов.
5. Передает заказы в обработку на склад.
